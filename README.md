# Kana Pop — ひらがな読みマージパズル

**本番URL: https://kana-pop-seven.vercel.app**

文字メダルを落として合体させ、ひらがなを「読む」練習をするダーク基調のマージゲーム。

- Vite + React + TypeScript
- 物理: Matter.js（描画は Canvas 2D の自前レンダラ）
- 音声: 提供された収録ボイス（`public/voice/clips/*.wav`）だけを使う。音声合成など生成した声は使わず、収録が無い文字は無音

## ゲーム仕様

- **1ステージ = 5文字**（全21ステージ）。小さい文字 → 大きい文字の順に進化し、最後の文字が最終形。
  あ・か・さ・た・な・は・ま・や・ら・わ（行ごと）／ が・ざ・だ・ば・ぱ（濁音・半濁音）／ 拗音①〜⑥。
  5文字に満たない や行・わ行は、直前の行の末尾の文字（め・も / れ・ろ）で埋めて5文字にそろえている。
- **出現**: ステージの5文字を「シャッフルした袋」から1周ずつ出す。同じメダルは連続しない。最終形も文字面で1周に1回出る。
  読みモードは各文字（最終形を除く）が文字面・読み面の2枚ずつ袋に入る（9枚で1周）。ふつうモードは5枚で1周。
- **最終形の進化**: 最終形+最終形 → 👑 → (👑+👑) 💎 → (💎+💎) 🌈 → (🌈+🌈) ステージクリア。バッジは 1→2→4→8。
  同じバッジどうしだけが合体し、近づくと吸い付く。🌈で虹ボーナス+300点。クリアで次のステージへ自動で進み、最終ステージで ALL CLEAR。
- **2つのモード**（タイトルで切り替え。既定は読みモード）
  - 📖 読みモード: 同じ文字の「文字面（あ）+ 読み面（a）」のペアだけが合体。色と大きさは全員同じ（半径32）。
    最終形になった後は面を問わず同じバッジどうしで合体し、弱く引き寄せ合う。
  - 🫧 ふつうモード: 同じ文字どうしが合体。レベル別の色と大きさ。
- **コンボ**: `min(5, 1 + floor(コンボ数/3))` 倍。読みモードは読み間違いで途切れ、ふつうモードは6秒以内に次の合体が続かないと途切れる。
  読み間違い = 落としたメダルが最初に触れた相手が「別の文字の反対の面」で、本当の相手が盤面にいるとき。
- 「視差効果を減らす」設定では、揺れ・振動・紙吹雪を出さない。

## 保存

`localStorage` の `kanapop-pop-v1`（Lv・経験値・ベスト・最大コンボ・クリア済み・モード）。壊れていたら初期化する。
ベスト/クリアはモード別（読み: `r1`…, ふつう: `1`…）。旧版のキー（`kanapop.progress` など）は読まない。

## ローカル開発

```bash
npm install
npm run dev
```

> ⚠️ Google ドライブ上（G:\My Drive\...）では `npm install` が EBADF で失敗する。ローカルディスクに clone して開発すること。

`?e2e` を付けて開くと、自動テスト用に `window.__pop`（エンジン）を参照できる。

## 声を差し替える

`public/voice/clips/<名前>.wav` を置き、`src/game/voiceClips.ts` の `CLIP_NAMES` に名前を足す（足した名前が鳴る。足さない文字は無音）。
利用規約（音声の再配布の可否）は使う声ごとに必ず確認すること。
